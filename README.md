# Sri Vari Constructions Website

A simple static website for Sri Vari Constructions showcasing company information, services, contact details, and project previews.

## Features

- Clean single-page layout with a background image
- Company information section with who we are and what we bring
- Project cards with clickable detail modal views
- Language toggle for English and Telugu
- Contact section with email, phone, and address

## How to use

1. Open `index.html` directly in a browser.
2. Or use VS Code Live Server:
   - Install the Live Server extension
   - Right-click `index.html`
   - Select `Open with Live Server`
3. Click any project card to view location, description, and photo gallery details.
4. Use the language buttons at the top to switch between English and Telugu.
